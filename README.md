# cargoexpress.is website

The public website for Cargo Express ehf. Plain HTML and CSS, generated by a small Python script from templates and content files. No database, no framework.

- **Icelandic** is the main language at `/`, **English** at `/en/`.
- Hosting: Netlify (planned). Every push builds a preview; the live site changes only when the COO approves.
- Plan and go-live checklist: `../PLAN.md`. Design reference: `../mockup/homepage.dc.html` and `../wix-build-guide.md` (design spec).

## Where things are

| Path | What it holds |
|---|---|
| `content/site.json` | Facts shared by both languages: contact details, airlines (hub, AWB prefix, tracking link), key figures, team |
| `content/is.json`, `content/en.json` | All page text, one file per language, same keys in both |
| `templates/` | Page layouts (Jinja2): `base.html` (top bar, header, footer), `home.html`, `thanks.html`, `privacy.html`, `404.html`, `map.svg` (hero illustration), `icons.html` |
| `static/` | Copied as-is: `css/site.css`, `js/track.js` (AWB lookup), `img/`, `_redirects` |
| `build.py` | Builds everything into `dist/` |
| `netlify.toml` | Netlify build command and headers |
| `dist/` | Generated output. Never edit; never commit |

## Build and preview

Needs Python 3.10+ and Jinja2 (`pip install -r requirements.txt`).

```bash
python build.py            # build into dist/
python build.py --serve    # build, then open http://localhost:8000
```

From the project root on the COO's Mac: `.venv/bin/python website/site/build.py --serve`.

The build prints any **[PLACEHOLDERS]** still on the site and any open checks marked `_check` in `content/site.json`. Both lists must be empty before go-live.

## Common changes

- **Text:** edit `content/is.json` and `content/en.json` (keep the same keys in both).
- **Team member, phone, email:** `content/site.json` → `team`. Roles are translated in each language file under `team.roles`.
- **Airline:** `content/site.json` → `airlines` (`awb_prefix` only once confirmed; `null` leaves it out of the track box), plus its onward text under `network.onward` in both language files.
- **Colours and spacing:** variables at the top of `static/css/site.css`.

## Quote form

Handled by **Netlify Forms** (`data-netlify="true"`, form name `quote`). Netlify spots the form when it deploys; set the email notification to export@cargoexpress.is under *Site configuration → Forms → Form notifications*. Spam: Netlify's filter plus a hidden honeypot field (`company_website`). The form sends visitors to `/takk/` or `/en/thanks/`.

## Search engines

Only a build with `CONTEXT=production` (set by Netlify for the live site) can be indexed. Every other build gets `noindex` and a `robots.txt` that blocks everything, so previews never show up on Google.

## Before go-live

- [ ] Resolve the `_check` items in `content/site.json` (Finnair tracking link, Air Canada/Norwegian prefixes, name spellings).
- [ ] **Self-host the fonts** (Inter, Space Grotesk) instead of loading them from Google, so visitors' IP addresses aren't sent to Google. Download the `.woff2` files, put them in `static/fonts/`, add `@font-face` rules to `site.css`, and remove the Google Fonts links in `templates/base.html`.
- [ ] Netlify: set the form notification email; add `www.cargoexpress.is` (primary) and `cargoexpress.is`.
